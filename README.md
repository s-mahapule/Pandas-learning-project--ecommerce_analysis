## 📌 Overview
This project focuses on performing end-to-end data exploration, cleaning, and financial metrics extraction from an online retail dataset. Built as a hands-on project to master data manipulation, aggregation, and analysis using **Python** and **Pandas**.

## 📊 Dataset
* **Source:** [UCI Machine Learning Repository — Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii)
* **Description:** Contains real-world transactions occurring between 01/12/2009 and 09/12/2011 for a UK-based registered non-store online retail enterprise.

## 🚀 Progress & Roadmap

### ✅ Completed Analysis
- [x] **Data Reconnaissance** — Initial inspection of data types, structure, missing values, and distributions.
- [x] **Data Quality Investigation** — Outlier detection, handling null values, and cleaning duplicate records.
- [x] **Revenue Calculation** — Calculating line-item totals, invoice summary metrics, and net sales volume.
- [x] **Cancellation Analysis** — Tracking returned/cancelled orders (`C` prefix) and measuring their impact on revenue.

### 🚧 Planned Features
- [ ] **Product Analysis** — Identifying top-performing SKUs, product bundles, and Pareto distribution.
- [ ] **Customer Analysis** — RFM (Recency, Frequency, Monetary) segmentation and purchase patterns.
- [ ] **Geographic Analysis** — Cross-country sales breakdowns and market performance.
- [ ] **Time-Series Analysis** — Hourly, daily, and seasonal trends.
- [ ] **Business Insights & Recommendations** — Final executive summary and actionable takeaways.
